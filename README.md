## ✅ Реализованные требования

### 1. Три способа подключения стилей

| Способ | Где реализовано |
|--------|-----------------|
| **Внешний** | `src/style.css` через `<link rel="stylesheet" href="src/style.css">` |
| **Внутренний** | `<style>` в `<head>` — стили для полей ввода (`height`, `font-size`) |
| **Встроенный (inline)** | `<h1 style="text-align: center;">` |

### 2. CSS-переменные в `:root`

```css
:root {
    --color-main: silver;      
    --color-accent: black;    
    --font-main: Arial, sans-serif;
    --font-heading: Georgia, serif;
}
```

### 3. Позиционирование

| Тип | Где применяется |
|-----|-----------------|
| `static` | форма `.contact form` |
| `relative` | `.card-container`, `header` |
| `absolute` | `.card-container::before` (декоративный элемент) |

### 4. Состояния элементов

- `:hover` — ссылки, карточки навыков, кнопка
- `:active` — ссылки, кнопка
- `:focus` — ссылки, кнопка (со свечением `box-shadow: 0 0 10px`)
- `:visited` — ссылки в навигации

### 5. Контрастность

Контраст текста на странице — **не менее 4.5:1** (чёрный текст на серебристом фоне ≈ 10:1).

## 🎨 Особенности Варианта 12

- **Карточки навыков** оформлены в стиле «металлических пластин»:
  - металлический градиент (`linear-gradient` от `#f5f5f5` через `silver` к `#8f8f8f`);
  - длинная тень при наведении (`box-shadow` с двумя слоями).
- **Кнопка отправки формы** при `:focus` получает свечение: `box-shadow: 0 0 10px silver`.
- **Inline-стиль** `text-align: center` применён к заголовку `<h1>`.
- **Внутренний блок `<style>`** задаёт стили для полей ввода (высота и шрифт).
- В переменных: основной цвет — **серебристый**, акцент — **чёрный**.
